# Portafolio de Jacobo Morales Londoño

Portafolio profesional responsive hecho con HTML, CSS, JavaScript y **Bootstrap 5.3.8** (Parcial 2, Desarrollo Web).

## Secciones
Sobre mí, Formación, Proyecto (ETS InfoPlus), Lenguajes y tecnologías, Áreas de interés y Contacto.

## Responsive
Probado en tres anchos: celular (375 px), tableta (768 px) y escritorio (1280 px), con la grilla y el menú colapsable de Bootstrap más ajustes propios en `styles.css`.

## Estructura
- `index.html`, `styles.css`, `script.js`: portafolio.
- `proyecto-ets/`: sitio ETS InfoPlus, proyecto académico en equipo.

Bootstrap y las fuentes se cargan desde CDN, por lo que se necesita internet. Sitio desplegado con GitHub Pages.
